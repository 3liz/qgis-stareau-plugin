# Database structure

The documentation of all the schemas of the plugin (tables, views, columns, constraints, relationships and functions)
is generated by [SchemaSpy](https://schemaspy.org/). Select a schema to see its tables and relationships:
most of the relationships are foreign keys from the network tables to the value lists of the schema `stareau_valeur`.
The tables of the StaR'Eau geostandard are described in [Tables and fields](tables.md).
